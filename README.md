# Employee Management System with HR Analytics Dashboard

## Overview
A Python-based employee management application with MySQL integration and an HR analytics dashboard.

## Technologies
- Python
- MySQL
- Pandas
- Matplotlib

## Features
- Employee registration and record management
- Search, update, and delete employee records
- Salary and workforce analytics
- Data visualization
- CSV data export

## How to Run
1. Install Python and the required Python libraries.
2. Set up the MySQL `company` database.
3. Configure your database credentials.
4. Run the Python application.
